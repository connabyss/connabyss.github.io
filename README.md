# connabyss.github.io

The home page at https://connabyss.github.io/ : one page that links to every game and tool. Each game lives in its own repo.

- `index.html`: the home page. Pictures are in `img/` (640x400 webp).
- `404.html`: shown for any address that doesn't exist.
- `sitemap.xml`: every live page. Add new GitHub Pages games here.
- `googledacb01e4b1f47ade.html` and `BingSiteAuth.xml`: search engine ownership files. Never delete them.
